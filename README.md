# Appointment-Booking-Form
The Appointment Booking Form is a simple web-based application developed using HTML, CSS, and PHP. This project allows users or patients to easily book an appointment by entering their personal and appointment-related details through a user-friendly form interface.

The form collects important information such as patient name, contact number, appointment date, appointment time, reason for visit, and an additional message. HTML is used to design the structure of the form, while CSS is used to create an attractive and responsive layout that improves user experience.

PHP is used as the backend language to process the form data after submission. When the user clicks the Book Appointment button, PHP captures all entered details, validates them, and stores the appointment information inside a separate text (.txt) file. This allows appointment records to be saved without using a database, making the project simple and beginner-friendly.

This project helps in understanding form handling, data processing, file handling, and basic user interaction in PHP. It can be used as a basic hospital or clinic appointment booking system and is useful for beginners who want to practice backend development concepts.
